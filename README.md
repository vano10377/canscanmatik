# CanScanmatik

Windows-приложение для чтения CAN-шины через `Scanmatik` по интерфейсу `J2534`.

## Что умеет

- автоматически ищет `SM2` / `SM3` в реестре `PassThruSupport.04.04`
- открывает J2534 DLL из установленного Scanmatik-драйвера
- подключается к raw `CAN` с выбранной скоростью
- читает `11-bit` или `29-bit` кадры
- поддерживает рабочие профили `CAN1` / `CAN2` / `CAN3` / `CAN4`
- умеет сортировать таблицу по `ID` или по активности
- подсвечивает байты, которые изменились в последнем кадре того же `ID`
- показывает последние кадры по ID, счётчик и период
- ведёт текстовый лог потока, пишет лог-файлы сессии и умеет сохранять таблицу в CSV
- сохраняет текущий список CAN ID в текстовый файл и автоматически пишет `last_ids` для активной шины при отключении

## Важно

- проект собирается в `x86`, потому что установленный у вас драйвер Scanmatik зарегистрирован как `32-bit`
- текущая версия ориентирована на чтение raw CAN через стандартный J2534-канал
- выбор `CAN1/CAN2/...` внутри приложения разделяет рабочие сессии, а физическая маршрутизация линии по-прежнему задаётся через `Scanmatik Config`
- если нужна отдельная логика под второй физический канал, CAN-FD или специальные линии SM3, это можно добавить следующим шагом



## Запуск

1. Подключите Scanmatik.
2. Запустите приложение.
3. Выберите адаптер, скорость и тип идентификаторов.
4. Нажмите `Подключить`.
